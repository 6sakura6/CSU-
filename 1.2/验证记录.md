# 1.2.4 轻量动态背景

日期：2026-11-04（北京时间）。两层预先柔化的 CSS 渐变使用位移、缩放和透明度形成缓慢流动与颜色交融，无新增依赖。移除轻量入口的背景 PNG/base64 注入，打包仅保留需要的图标和许可证；旧 Qt 界面继续保留其背景资源。半透明卡片省去逐帧的实时背景模糊。

本机 1184×821、96 DPI 窗口短测，统计 Python 与该 WebView2 环境的进程 CPU 时间总和，每组预热 2 秒、采样 8 秒，按占满一个逻辑核心为 100%：优化前动态模糊卡片约 4.58%，省去实时模糊后约 2.67%；多轮复测中，静态与动态均约 1.5%–2.1%；隐藏采样存在波动。这是本机短时样本，不代表所有硬件，也没有直接测量 GPU 占用。

实际验证托盘隐藏后动画时间冻结、恢复后继续、最小化暂停与还原、弹窗暂停背景及模拟系统减少动画偏好均通过。19 项界面桥接回归通过；最终 1.2.4 打包程序本轮 34 项完整离线自检全部通过，包括本地模拟业务流程。此前开发版和旧版对照曾出现业务检查失败，本轮通过不代表其间歇失败原因已被定位或修复；未进行真实学校打卡。完整打包目录约 27.09 MB，原 1.2.3 约 28.47 MB。最终版增强了流动幅度与颜色区分，避免启动阶段过于缓慢；连续 8 秒自然播放可测得背景颜色变化。发布构建位于 `dist/release-v1.2.4/平安打卡助手`。
