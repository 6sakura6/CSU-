# 1.1 系列

- `source`：Git 标签 v1.1.1 的完整原始源码，附该版本的使用说明、验证记录和设计说明。
- `dist/1.1.0`、`dist/1.1.1`：原有两个版本的完整程序和各自 data。
- `dist/release-v1.1.1`：正式发布时的完整构建，包含当时随包保存的源码。
- `发布包`：1.1.0 轻毛玻璃版、1.1.1 圆角版，以及正式发布的 v1.1.1 ZIP。
- `验证资料`：原界面设计、截图、构建和验证记录；`build` 为原根目录的 Qt 构建缓存。

运行源码时在本目录执行 `python source/app.py`，构建执行 `./source/build.ps1`。源码依赖以本目录 `source/requirements.txt` 为准。

1.1.0 没有独立 Git 标签或随包源码，保留其原程序与 ZIP；当前主源码为 v1.1.1，未将其标作 1.1.0 原始快照。来源见 `源码版本清单.json`。
