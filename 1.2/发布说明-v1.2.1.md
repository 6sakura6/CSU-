# 平安校园打卡助手 v1.2.1

轻量版保留账户、每日定时、随机延迟、定位、校园网、自启动、托盘、取消与结果复核，完整运行目录控制在 100 MB 以内。源码和历史版本按 1.0、1.1、1.2 系列整理，当前开发入口为 `1.2/source/lite_app.py`。

## 本次变化

- 使用系统 WebView2 绘制圆角毛玻璃界面，通过系统 Edge / Chrome 的 CDP 执行网页流程；不捆绑 Qt、Playwright、Node 或独立浏览器引擎。
- 修复服务大厅跳转统一认证页后停住、未继续自动填写账号密码的问题，改为跟随当前主页面的加载状态。
- 保留原生圆角、边缘缩放、动效、托盘、旧版加密配置导入和备份；源码目录调整后同步适配构建路径。

## 下载与升级

- `CSU-Peace-Checkin-Windows-v1.2.1.zip`：完整 Windows 程序。解压整个文件夹，运行 EXE，保留 `_internal`。
- `CSU-Peace-Checkin-Windows-v1.2.1-hotfix.zip`：仅供已安装 1.2.0 的用户。先从托盘退出，再用包内 EXE 覆盖原目录同名文件，保留原 `_internal` 和 `data`。
- `CSU-Peace-Checkin-Source-v1.2.1.zip`：对应发布提交的完整公开源码，包含三个版本系列；当前轻量版源码位于 `1.2/source`。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

从更早版本升级时，可使用新版底部“导入旧版数据”，选择原 `data` 文件夹；核对设置后再开启定时。加密数据仍绑定原 Windows 用户。

## 环境与验证

Windows 10 / 11 x64，需要已安装 .NET Framework 4.8、Microsoft Edge WebView2 Runtime，以及 Edge 或 Chrome。共享系统组件和使用后产生的数据、日志、缓存另计；程序不自动下载运行库。

230 项源码回归通过；打包程序的 31 项界面检查和 Edge / Chrome 共 20 项后端离线检查通过。真实新会话已验证登录页识别及账号密码自动填入。验证码和二次认证仍需人工处理；本次没有提交真实学校打卡，学校开放时段的范围判断、电脑设备定位和真实校园网认证仍需现场验证。

发布文件仅包含公开源码和运行文件，不含个人账户、学校会话、坐标或运行日志。完整运行目录的精确字节数见 `size-report.json`。
