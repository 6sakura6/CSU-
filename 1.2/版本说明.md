# 1.2 系列

- `source`：当前版本 **1.2.4**，包含轻量动态背景及启动窗口居中修复。
- `dist/release-v1.2.4/平安打卡助手`：最新程序；`dist/1.2.2`、`dist/1.2.1` 和 `dist/1.2.0` 保留先前版本。
- `发布包`：保留 1.2.0、1.2.1 和 1.2.2 完整 ZIP、专用修复包与校验文件。1.2.2 完整初始目录约 28.48 MB。
- `dist/1.2.1-hotfix`：修复包的解压内容。
- `dist/中间构建`：开发中的多次 1.2.0 构建；`dist/验证版` 和 `发布包/验证版` 保留早期小型验证程序。
- `prototype/lite`：早期验证程序源码及构建工具。
- `验证资料`：后端迁移、完整界面、体积研究和登录修复的原始记录，含私有调试数据，已整体从 Git 排除。
- `build`：轻量程序和验证程序的原构建缓存。根目录 `../work/lite-venv` 为共享 Python 环境，构建脚本会自动查找，也可显式传入 `-Python`。

在本目录执行：

```powershell
../work/lite-venv/Scripts/python.exe source/lite_app.py
./source/build.ps1
```

1.2.0 没有独立保存的源码快照，保留原完整程序和发布包；当前主源码为 1.2.4。来源见 `源码版本清单.json`。各程序的账号与配置保留在各自原 data 中，使用新版“导入旧版数据”可选择 `dist/1.2.0/平安打卡助手/data`。
