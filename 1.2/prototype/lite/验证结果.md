# 轻量验证版 0.1.0 验证结果

日期：2026-11-03。验证对象为 Windows x64 可运行程序 `CSUCheckinLitePrototype.exe`，源码位于本目录，完整程序位于项目的 `dist/lite-prototype/CSUCheckinLitePrototype/`。

**实测完整目录约 28.2 MB，小于 100 MB。** 该数字包含 EXE、全部随附 Python/.NET 桥接/WebView2 SDK 运行文件、界面与图片、说明、许可和 JSON 验证记录。精确字节数见程序目录内的 `size-report.json`。未携带 Qt/PySide6、Playwright、Node、NumPy、Pillow、Tk 或独立 Chromium 引擎。

这是基础架构验证版，尚未迁移完整学校登录、打卡调度控制器、校园网操作等所有正式功能。不能据此声称完整功能版已缩小到 28.2 MB。

## 已验证

- 7 项自动测试通过：复用原有 DPAPI、账户隔离与排期规则；设置重启后读取；设置及状态不泄露验证文字；输入长度验证；桥接仅暴露指定方法；验证任务互斥与取消；CDP 等待可取消及超时有界。
- 源码模式与打包 EXE 的完整自检均通过。
- 打包程序实际加载系统 WebView2，JS/Python 桥接保存并回读验证设置成功，卡片启用了 `blur(24px) saturate(1.25)`。
- Edge 与 Chrome 均实际启动独立临时浏览器，填写本地表单、捕获服务响应并读取正文、验证初始化脚本、读取 HttpOnly 测试 Cookie，再用新页面查询确认会话可复用。
- 定位协议使用预设的本地测试坐标成功；没有读取用户实际位置，也没有验证学校定位流程。
- 实际 WinForms 原生窗口区域在普通尺寸和 900×720 紧凑尺寸下裁切为圆角，窗口角点不属于可见区域；最大化后填满，还原后恢复圆角。
- 自检确认托盘图标存在，窗口可隐藏并恢复；设置弹层可打开关闭；普通和紧凑尺寸无横向内容溢出。
- 使用 computer-use 技能实操打包程序，点击「运行完整验证」后正常显示通过；开启 5 秒倒计时后触发新一轮验证并完成；设置弹层视觉检查正常。
- 自检的独立浏览器、测试 HTTP 服务和浏览器临时配置目录均已清理。

原始打包验证结果随程序提供为 `verification.json`；它验证的是本机测试页面，不涉及学校打卡。自动自检及 UI 实操没有访问学校、读取正式版凭据、提交打卡或改动自启动。

## 体积与系统依赖的边界

使用本机已安装的共享 Microsoft Edge WebView2 Runtime 和 .NET Framework。包内提供 WebView2 SDK/Loader 桥接文件，未包含 WebView2 浏览器 Runtime；程序没有自动下载或安装 Runtime 的逻辑。

本机注册的 WebView2 版本为 157.0.4341.36，实际 WebView2 Environment 报告 157.0.4341.36 beta；.NET Framework Release 为 533320。当前结果只说明这台 Windows 电脑上的验证通过，尚未验证 Windows 10、缺少 Runtime 的干净机器或其他 Runtime 版本。

28.2 MB 是初次解压的应用文件体积，不含系统共享 Runtime、已有 Edge/Chrome，以及运行产生的设置、WebView2 缓存和临时页面。它们不能被当作不存在的占用。缺少共享 Runtime 的机器仍需另行安装，此安装体积不包含在验证包中。
