# 轻量迁移第 1、2 步完成记录

日期：2026-11-03。验证包版本：0.2.0-backend。

已完成无界面业务核心和轻量浏览器驱动的代码迁移，并将二者包含在可执行验证包中。完整业务界面属于后续第 3 步；真实学校环境验证尚未进行。

## 交付内容

1. `source/service.py`：不依赖 Tk/Qt/WebView 的业务控制器。包含账户与配置保存、DPAPI/旧数据格式复用、定时与随机排期、重试、每日完成记录、独立校园网任务、互斥与取消、退出、防休眠及注入式自启动注册。
2. `source/schedule_policy.py` 与 `source/browser_flow.py`：排期和网页规则从旧模块中拆出，供新旧实现共用，减少规则迁移时的行为差异。
3. `source/cdp_transport.py`、`source/cdp_browser.py`、`source/lite_browser.py`：系统 Edge/Chrome 的独立实例和轻量 CDP 驱动。覆盖正常登录、隐藏重复表单、密码框聚焦、人工验证码等待、菜单入口、班次、位置、会话、停止、提交与新页面复核。
4. `source/lite_cli.py` 与 `source/backend_selftest.py`：可执行的无界面入口和端到端验证。打包 EXE 新增 `--backend-self-test`，不依赖完整业务界面即可检查实际后端。

端到端验证实际走过：本地合成的认证表单 → 业务大厅 → 最新菜单 → 班次与定位检查 → 只检查不提交 → 关闭浏览器并加密保存会话 → 新浏览器恢复会话 → 本地模拟提交 → 新页面重新查询核验 → 本地完成记录 → 次日排期 → 再次运行跳过重复提交。每轮独立浏览器及临时配置目录都已清理。

保存的 Cookie 字段兼容旧 storage-state 格式；恢复 localStorage 仅初始化一次，不在每次导航时覆盖新 token。仅检查和校园网任务不会写入打卡完成记录。工作线程已结束但结果尚未回收时仍保持忙碌，跨午夜完成记录按浏览器核验日期归属。

## 体积

包含新后端的完整应用目录约 **28.4 MB**，小于 100 MB。精确字节数以包内 `size-report.json` 为准，已计入程序、运行库、界面资源、许可、说明和验证记录。

包使用系统已有的 WebView2 与 .NET Framework，没有打包或自动下载独立浏览器 Runtime；系统 Runtime 和运行时数据/缓存不计入初次解压的应用文件体积。真实用户缺少 Runtime 时仍需另行安装。该包包含业务后端及基础演示界面，不能据此代替尚未完成的完整轻量版现场验收。

## 证据与使用

包内 `backend-verification.json` 为实际打包 EXE 的新后端结果，`ui-verification.json` 为打包演示界面的结果，`轻量后端说明.md` 提供给下一阶段界面的 API 和开发入口。

本地原始测试记录：

- `work/lite-validation/full-regression-step12-final.txt`
- `work/lite-validation/backend-both-final.json`
- `work/lite-validation/packaged-backend-step12.json`
- `work/lite-validation/packaged-ui-step12.json`

自检可执行命令：`CSUCheckinLitePrototype.exe --backend-self-test --report <结果文件路径>`。默认验证 Edge 与 Chrome；使用 `--channel edge` 或 `--channel chrome` 指定单个浏览器。

## 验证边界

本次全部浏览器业务页面请求均通过 CDP Fetch 在本地返回或中止；没有继续发送到真实学校服务，没有读取正式账户、执行真实校园网认证或提交真实打卡。定位使用预设的合成测试坐标，电脑真实定位、学校页面/账户状态差异仍需后续真实环境检查。

完整 WebView2 业务界面和真实学校环境验证是下一阶段工作；已发布正式版和用户数据没有被这个验证包替换，也没有发布新的正式 Release。
