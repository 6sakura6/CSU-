# 平安打卡助手 1.0.8

适用于 Windows 10 / 11 64 位，电脑需已安装 Microsoft Edge 或 Google Chrome。可直接运行 exe，不需要自行安装 Python。

## 首次使用

1. 保留整个“平安打卡助手”文件夹，双击其中的 **平安打卡助手.exe**。`_internal` 文件夹是运行所需文件，请与 exe 放在一起。每次打开都会显示免责声明：“本程序仅供学习和测试使用，请在下载后 24 小时内删除。”点击“我已阅读并同意”后进入主界面；点击“退出程序”或关闭提示窗口则退出。
2. 在程序窗口填写校园账户（学号 / 工号）和密码；密码不用发送到聊天中。
3. 设置每日打卡时间、重试截止时间与重试间隔，点击“保存配置”。默认时间为 **21:00**，重试至 **23:25**，每 **5 分钟**重试。所有时间按北京时间计算。
4. 先点击 **“仅检查登录与定位”**，验证本机登录、当天班次及定位能否正常工作。此按钮不会提交打卡。
5. 检查通过后点击 **“开始定时”**。启动成功后按钮由蓝色变为红色，并显示 **“定时已启动”**；停止或因问题暂停后恢复蓝色。程序到点会打开浏览器，先进入服务大厅，从本次加载的功能菜单中读取“平安打卡”的实际入口，再进入打卡页面读取当天的学校规则。

1.0.1 已修复大厅入口无法识别的问题：大厅卡片名称在图片中，且位于内部滚动列表。现在读取的是开发者工具“网络”面板可以看到的同一份菜单数据，按功能名称获取地址，不依赖滚动位置、图片文字或固定的打卡页面网址。每次执行和结果核验都会重新从大厅获取入口，并去除历史成功参数。

程序尚未使用你的真实账户完成登录及打卡联调，首次运行请关注窗口里的结果。“仅检查”通过也不等于已实际打卡，应以正式运行后重新查询到的当天记录为准。

## 定时行为

- 每天从设置的时间开始检查；如果启动程序时已经过了该时间，但还没到重试截止时间，会立即检查。
- 每次重新读取学校的开放时段；不在学校时段内、当天不可打卡时，不提交。
- 当天已打卡或免打卡时跳过。提交后在新页面重新从大厅菜单获取当前入口，再查当天记录，确认成功后当天不再执行。
- 如果当前服务菜单没有“平安打卡”，程序会明确提示检查账户角色或学校菜单配置，不会猜测地址继续提交。
- 普通网络错误按间隔重试。密码错误、验证码等待超时、定位失败、考勤范围不符或页面结构改变时暂停定时，需要处理后重新点击“开始定时”。
- 登录遇到验证码或二次认证时，会提示你在浏览器中处理，最多等待 5 分钟。程序不自动识别验证码。
- 点击“立即检查并打卡”会马上检查，满足学校的时段、定位和班次条件后提交；它不等待每日设定时间。
- 点击“停止”会取消定时并请求停止当前操作。正在等待网络时可能需要几十秒；已经发出的请求不能撤回，下次会先查状态。

## 程序运行与电脑状态

开始定时后会临时阻止电脑自动睡眠，停止或退出后恢复正常睡眠行为。手动睡眠、关机、断网和退出 Windows 账户仍会中断执行。

主界面提供 **“开机自启动（登录 Windows 后在托盘运行）”** 选项，默认关闭。勾选并确认提示后立即保存；此后登录当前 Windows 账户时，程序会进入系统托盘，并恢复上次已开启的定时。如果上次点击了“停止”，开机启动只运行程序，不会自动开启定时。取消勾选会移除本目录程序的自启动项。

启用时的确认包含免责声明和后台启动行为。开机启动沿用这次确认，通过托盘通知及运行记录显示声明，不等待弹窗点击；手动打开新进程仍显示原有免责声明。只对当前 Windows 账户注册，无需管理员权限，启动命令不包含校园账户密码。

自启动发生在登录 Windows 之后，系统可能延迟启动。若在 Windows 的“启动应用”中禁用了本程序，需要在那里重新启用。移动程序目录前应先取消旧位置的自启动，再在新位置重新勾选。

点击主窗口右上角的 **×** 会隐藏窗口并转入 Windows 系统托盘，**已开启的定时和正在进行的操作继续运行**。首次隐藏会显示托盘提示；图标可能位于任务栏右下角的“显示隐藏的图标”区域。

点击托盘图标或右键选择“显示主窗口”可恢复界面。再次双击同一目录中的程序，也会显示已经运行的窗口。右键托盘图标选择 **“退出程序”**，或点击主界面的同名按钮，才会真正退出；如果正在执行任务，会先请求停止当前操作，结束后移除托盘图标并释放程序锁。

真正退出后不再执行定时；如果退出前启用了定时，下次重新启动会恢复。手动启动需先同意免责声明；已确认并启用的开机自启动会按上述规则进入托盘。点击“停止”后，暂停状态会保存，下一次打开不会自动恢复。托盘运行不会自动开启尚未启动的定时。

浏览器由程序单独启动，不读取你正在使用的 Edge / Chrome 配置，也不会关闭你原有的浏览器窗口。

## 本地保存的数据

程序会在 exe 同目录生成 `data` 文件夹：

| 文件 | 内容 |
| --- | --- |
| `credentials.dat` | 加密保存的校园账户和密码 |
| `session.dat` | 加密保存的浏览器登录状态，减少重复登录 |
| `location.dat` | 加密保存的手动 GPS 坐标 |
| `settings.json` | 每日时间、重试间隔及是否自动恢复定时 |
| `completed.dat` | 按账户加密保存的当天完成标记 |
| `activity.log` | 运行记录，不写入账户密码、登录令牌或经纬度 |

账户、密码、登录状态和完成记录使用 Windows DPAPI 加密，绑定当前 Windows 用户；复制到其他电脑或换 Windows 用户后需要重新配置。日志只记录操作状态。程序自动填入密码时，仅在学校统一认证域名 `https://ca.csu.edu.cn` 的预期登录页面填写。

密码输入框在保存后会清空。再次修改时间时，密码留空表示沿用已保存密码；更换账户时需要重新填写密码，并清除之前账户的登录状态。

## 定位说明

默认使用电脑自动定位。没有定位设备时，可点击主界面的“定位设置”，选择“手动输入定位”，分别填写纬度和经度，然后点击“校验并换算”和“保存定位设置”。

支持以下两种输入格式：

- 十进制度：纬度 `30.25833333`、经度 `120.50833333`。
- 度分秒：纬度 `30°15′30″`、经度 `120°30′30″`，也支持英文单引号、双引号及“度、分、秒”文字。

以上数值仅用于说明格式。经纬度填写在各自的输入框，不要粘贴成一个逗号分隔的字符串。北纬、东经为正；南纬、西经使用负数或方向文字。纬度范围为 -90 至 90，经度为 -180 至 180；分和秒必须小于 60。

手动模式使用本人当前所在地的 WGS84 / GPS 坐标，适合手机指南针显示的 GPS 位置。其他地图坐标系需先转换。程序将坐标提供给浏览器定位接口，学校网页继续进行坐标转换、地址解析和考勤范围判断；不会自动放行学校拒绝的位置。手动坐标仅在本机加密保存，默认留空，不预置测试地点。

如提示无法定位，请在 Windows 设置的“隐私和安全性 → 位置”中检查定位是否可用，并确认浏览器能取得定位。电脑定位精度受设备和网络影响；本人与电脑异地时，电脑位置不能代表本人当时的位置。

如果页面显示今天已打卡或免打卡，“仅检查”会使用浏览器定位单独测试；它与学校地图组件的定位供应商可能不同。如该测试失败，可查看真实打卡时段的学校页面定位情况。

## 版本验证

已进行加密存储、日期与时段判断、跨账户隔离、重复运行锁、离线浏览器流程、重复打卡跳过、错误成功弹窗、验证码不自动提交等测试。

真实学校手机登录页已检查账户、密码和登录按钮的可用性，测试过程中没有填写真实校园账户，也没有向学校提交打卡。完整的真实账户登录、定位和提交结果仍需首次运行验证。学校更新登录页或打卡流程后，程序可能需要更新。

## 源代码与构建

`source` 文件夹包含 Python 源代码、依赖版本与测试。开发环境可执行：

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python app.py
```

构建时使用 PyInstaller 的 `--windowed --onedir` 方式，Playwright 使用电脑现有的 Edge / Chrome，不需要另外下载浏览器。重建时请把生成目录设到临时工作目录，不要覆盖保存源代码或账户文件的目录。

实现参考：[Playwright 登录状态](https://playwright.dev/python/docs/auth)、[设备模式与权限](https://playwright.dev/python/docs/emulation)、[Microsoft DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。
